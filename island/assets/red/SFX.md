# pret/pokered sound-effect scripts

These are Game Boy tone scripts in [pret/pokered](https://github.com/pret/pokered) `audio/sfx/` (`duty_cycle`, `square_note`, pitch sweep, `sound_ret`). They are not WAV files, and they are not copied into this repo.

The live demo does not serve this folder. Browser playback stays on Web Audio or Kenney samples.

| Effect | pret/pokered path |
| --- | --- |
| Ball toss | `audio/sfx/ball_toss.asm` |
| Ball poof | `audio/sfx/ball_poof.asm` |
| Caught Pokémon | `audio/sfx/caught_mon.asm` |
| Collision | `audio/sfx/collision_1.asm` |
| Ledge hop | `audio/sfx/ledge_1.asm` |
